# Services

We are a software and AI development company. Our core services are:

**AI Development**
We build custom AI systems including RAG chatbots, voice AI receptionists,
AI agents with tool use, and workflow automation using n8n. We work with
LangGraph, OpenAI, and vector databases such as Supabase pgvector.

**Web Development**
We build full-stack web applications using React, FastAPI, Node.js, and
PostgreSQL. This includes dashboards, internal tools, and customer-facing
websites.

**RAG Chatbot Development**
We design and build Retrieval-Augmented Generation chatbots grounded in a
client's own documentation, so answers are accurate and not hallucinated.

**AI Automation**
We connect AI agents to business workflows using tools like n8n, allowing
automated lead capture, email drafting, scheduling, and notifications.

**Voice Agents**
We build AI voice receptionists using Vapi that can answer calls, respond
to inquiries, and route requests to the right team member.
